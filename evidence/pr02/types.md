# PR02 — типы сообщений и назначение полей

## Два основных топика

| Топик | Тип | Назначение |
|---|---|---|
| `/turtle1/cmd_vel` | `geometry_msgs/msg/Twist` | Команды движения черепашки: линейная и угловая скорость |
| `/turtle1/pose` | `turtlesim/msg/Pose` | Текущая поза черепашки: координаты, угол, скорости |

Тип позы выбран по выводу команды `ros2 topic type /turtle1/pose` → `turtlesim/msg/Pose` (ROS 2 Jazzy).

## Поля `geometry_msgs/msg/Twist`

`Twist` описывает скорость в свободном пространстве и состоит из двух `Vector3` — `linear` и `angular`.

| Поле | Тип | Назначение |
|---|---|---|
| `linear.x` | `float64` | Линейная скорость вперёд/назад (м/с) |
| `linear.y` | `float64` | Боковая линейная скорость (для `turtlesim` не используется) |
| `linear.z` | `float64` | Вертикальная линейная скорость (не используется) |
| `angular.x` | `float64` | Угловая скорость вокруг оси X (не используется) |
| `angular.y` | `float64` | Угловая скорость вокруг оси Y (не используется) |
| `angular.z` | `float64` | Угловая скорость поворота (рад/с) |

Для управления `turtlesim` достаточно `linear.x` (движение вперёд/назад) и `angular.z` (поворот).
